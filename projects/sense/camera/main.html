2D feature-tracking pipeline

Keypoint Detection: Implementing various detector types (e.g., SHITOMASI, HARRIS, FAST, BRISK, ORB, AKAZE, SIFT) to locate points of interest in the images.

Descriptor Extraction: Implementing multiple descriptor types to uniquely describe the detected keypoints based on their surrounding pixels.

Descriptor Matching: Matching the descriptors between successive frames using methods like Brute-Force (MAT_BF) or FLANN (MAT_FLANN), utilizing selector types like Nearest Neighbor (SEL_NN) and K-Nearest Neighbor (SEL_KNN) with a distance ratio test.

3D Object tracking

Convert pixel-level feature tracking to object-level tracking by associating bounding boxes across sequential frames.

ROI filtering: Given an image, using YOLO, bounding boxes are placed around specific objects of interest. Descriptor matching is only applied to these bounding boxes (ROI).

Association Logic: For every bounding box in the previous frame, the code identifies and extracts exactly one best-matching bounding box in the current frame based on the highest number of shared keypoint matches.

Output: The final result is delivered as a hashmap containing the optimized pairs of matching bounding box IDs across the two frames.

Lidar time-to-collision (TTC) Estimation

Compute the time remaining before a potential collision with a preceeding vehicle, based on the relative distance and velocity derived from Lidar points across sequential frames.

Avoided sensor noise by averaging the closest 20% of points instead of using a single, potentially rogue minimum distance point.

Calculated TTC using the filtered distance change between 2 consecutive frames over the time step.

Visualisation

Calculate the maximum and minimum spatial boundaries of each obstacle cluster to wrap them in 3D bounding boxes, creating clear "no-go zones" that a car must avoid to prevent collisions.

Setup 2

Upgrade the pipeline with the pcl::PointXYZI data type, allowing the system to handle both 3D spatial coordinates and laser reflectivity (intensity) data.

Data reduction and Region of Interest (ROI) selection

Use Voxel Grid downsampling to drastically thin out the data density to a 0.2m resolution. Apply a 3D CropBox to strip away irrelevant distant surroundings and reflections from the car roof.

Deployment

Use the segmentation, clustering, and bounding box tools. Tuning their operational boundaries so they can reliably detect and isolate noisy real-world urban obstacles.

Stream PCD

Re-architect the visualizer loop so it can continuously accept PCD frames. This turns it into a real-time, animated playback of an autonomous vehicle detecting obstacles on the move.

Benchmarking

Substitute PCL's built-in segmentation and clustering methods with the self-built 3D RANSAC and KD-Tree implementations, wrap them in a macro toggle to easily switch between the custom pipeline and the PCL standard.
