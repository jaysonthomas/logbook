Introduction

Overview

Localisation is the challenge of determining a robot's pose in a mapped environment. This is achieved by implementing a probabilistic algorithm to filter noisy sensor measurements and track the robot's position and orientation. Since a probabilistic model is used, the robot might have a few guesses as to where it is located. However, over time, it should hopefully narrow down on a precise location. B Popular Localisation algorithms:
  • EKF localisation
    • most common Gaussian filter that helps in estimating the state of non-linear models

  • Markov Localisation
    • Bayes filter Localisation algorithm. Markov maintains a probability distribution over the set of all possible positions and orientations the robot might be located at.

  • Grid Localisation
    • Also referred to as a histogram filter since it's capable of estimating the robot's pose using grids

  • Monte Carlo Localisation
    • Also known as a particle filter because it estimates the robot's pose using particles.
