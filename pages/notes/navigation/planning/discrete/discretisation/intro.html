Discretisation

To be able to apply a search algorithm, a configuration space must be reduced to a finite size that an algorithm can traverse in a reasonable amount of time, as it searches for a path from the start to the goal.

This reduction in size can be accomplished by discretisation. Discretisation is the process of breaking down a continuous entity, in this case a configuration space into discrete segments.

There are different methods that can be applied to discretize a continuous space. Examples: roadmap, cell decomposition, and gradient fields. Each has its own advantages and disadvantages balancing trade-offs such as time and the level of detail.
