Introduction

Overview

A discrete-time simulation helps simulate continuous dynamics (represented by ODEs which are always continuous), digitally on a PC.

Integration methods are used to go from continuous to discrete time. To go from discrete to continuous time (i.e. to get very smooth state transitions), interpolation is used; cubic spline interpolation being the most popular.

Euler integration is based on approximating the next discrete state by linearising the continuous dynamics using Taylor series expansion.
