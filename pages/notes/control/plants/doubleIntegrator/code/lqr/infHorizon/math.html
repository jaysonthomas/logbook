Infinite horizon LQR

Overview

This is an LQR stabilisation problem.

Control input

The optimal feedback gain $K$ is computed using LQR. The optimal control law is: $$\begin{align*} u_k &= -K \; x_k \\ &= - \left(k_1 \; q_k + k_2 \; \dot q_k \right) \\\\ K &= \begin{bmatrix} k_1 & k_2 \end{bmatrix} \end{align*}$$ Since the aim is to drive the state to 0, any value of position or velocity is an error and is used to determine the acceleration. If position is positive, controller applies negative acceleration to bring it back.

Cost matrices

LQR minimises the cost: $$ J = \sum_{k=0}^\infty x_k^\top Q_k x_k + u_k^\top R_k u_k $$ $$ Q = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix} $$ $$ R = 0.1 $$

Interpretation

  • Large state values are penalised.
  • Since control effort is not penalised as much, the controller can act aggressively.
