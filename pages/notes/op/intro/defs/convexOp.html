Convex optimisation

Definition

It minimises a convex objective function over a convex set, i.e. all constraints are convex sets.

Convex optimisation problems don't have any spurious local optima that satisfy KKT. If a local KKT solution is found, it is the global solution.

Practically, Newton's method converges fast and reliably (5-10 iterations max). The solution time can be bound for real time control.

Examples

Program is an old word for optimisation problem.

Linear Program (LP)

$f(x), c(x)$ are both linear.

Quadratic Program

Quadratic $f(x)$, linear $c(x)$.

Quadratically constrained QP (QCQP)

Quadratic $f(x)$, ellipsoid $c(x)$.

Second order cone program (SOCP)

Linear $f(x)$, cone $c(x)$.

Show up in aerospace, used in landing rockets. Thrust constraints are conic.

Reason for not having a quadratic cost function

Any convex QCQP can be converted into an SOCP. Any convex QP can be converted into a QCQP and then SOCP.

The core technique relies on introducing an auxiliary slack variable to upper-bound the quadratic cost function, moving it into the constraints. Specifically, a quadratic objective function can be reformulated into a second-order cone constraint bounded by this new slack variable. Because the new objective function is purely linear, quadratic costs can effectively be transformed into linear costs with quadratic (or conic) constraints. This trick allows a QP to be cast as an SOCP, meaning explicit quadratic cost functions are technically redundant—they can already be seamlessly handled through a clever change of variables.
