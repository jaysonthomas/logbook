Linear 1D (scalar) case

Without constraints

The aim is to find the best solution for $x$ such that LHS is approximately equal to RHS in the following linear algebra equation: $$ax\approx b$$
$$\begin{array}{ccl} a &:& \text{Slope} \\ x^* &:& \text{Solution to be found such that }ax^* = b \end{array}$$

Solution

$\|ax-b\|^2$ scores all the different options along the parabola to find the lowest point on the quadratic curve.
  • When the curve touches 0, $ax=b$. The 2 values diverge as the curve moves farther from 0.
  • If slope $a$ starts getting small, the solutions start getting worse - to achieve the same $b$, $x$ would need to be bigger.

With constraints

Adding constraints prevents a solution from going past a certain $x$ i.e. picks the smallest point on the curve that's within a certain regime. This is a more robust formulation because it is possible to put more information into it.

Example

$$\begin{align*} \min_x \quad & \|ax-b\|^2 \\ s.t. \quad & x\leq 2 \end{align*}$$ This equation says minimise over $x$ subject to $x \leq 2$ (the boundary of the search, the stop condition).

Solution

  • Create the scoring function to score all the points on the parabola for all possible $x$.
  • Limit the search to the constraint $x \leq{2}$.
  • Find the lowest point.
