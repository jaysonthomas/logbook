Linear higher dimension (vector/matrix) case

Without constraint

In an unconstrained minimisation problem, the aim is to find the lowest $x$ such that the LHS is approximately equal to the RHS in the following equation: $$ Ax \approx b $$

Solution

Create the following quadratic scoring/cost function: $$\|Ax-b\|^2$$
In higher dimensions, a 2D parabola turns into a quadratic bowl. The axes are $x_1$, $x_2$ and the objective is $\|Ax-b\|^2$. Every $x$ is scored by the cost function and the aim is to find the minimum.
Since the cost function is a convex bowl with ends pointing up, the solution becomes the $x$ where the gradient of the cost function is $0$: $$\begin{align*} \frac{\partial}{\partial x} \|Ax-b\|^2 &= \frac{\partial}{\partial x} [x^T A^T Ax - b^T Ax - x^T A^T b + b^2] \\ &= 2x^T A^T A - 2b^T A = 0 \\ (x^*)^T &= b^T \underbrace{A (A^T A)^{-1}}_{\text{Transpose of the} \atop \text{pseudo-Inverse}} \\ x^* &= A^{\dagger}b \end{align*}$$

Notes

[Gemini with images, Gemini]

$A (A^T A)^{-1}$ has no $b$ in it. This is why pinv does not need to know $b$ to be used. It is only possible to separate out $A$ and $b$ since the solution is linear in $b$.

The quadratic form is given by $[x^T A^T Ax - b^T Ax - x^T A^T b + b^2]$ but the shape is given by $A^T A$ in $x^T A^T Ax$.

When $A$ starts having small singular values, the bowl starts elongating just as in the case of the parabola with smaller slopes. It can elongate more or less in some directions/dimensions. As it gets long, the minimum $x$ starts leaving it, i.e. gets bigger.

With constraints

Boundaries/limits can be added to the problem i.e. find the best solution using the scoring function $\|Ax-b\|^2$ but don't go past some linear constraints (some reasonable velocities for example). $$\begin{align*} \min_x \quad & \|Ax-b\|^2 \\ s.t. \quad & \underbrace{Cx = d}_{\text{Linear constraint}} \end{align*}$$
A problem like this that has a convex quadratic objective (where the bowl goes up) and linear constraints is called a convex quadratic program. It's an important class of optimisation problems.

Quadratic programs cannot be solved with pen and paper unless they're very very small. There are efficient algorithms for solving them that can be run in real time at high speeds.
