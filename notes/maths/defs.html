Miscellaneous definitions

Limit

A limit is a value toward which an expression converges as one or more variables approach certain values.

Argmin

$$arg \min_x f(x)$$ Gives the corresponding value of $x$ for which $f(x)$ attains its minimum. It returns the argument that achieved the minimum.

Comparison to minimisation

$$\min_u f(x,u)$$ Finds the specific value of $u$ that makes the output of the function $f(x,u)$ as small as possible. It returns the minimum value of the function itself.

In a control context, when a solver evaluates $\min_u f(x,u)$, it isn't looking to just apply the minimum physical voltage or the smallest steering angle. It is searching the entire space of allowable control inputs to find the specific action that results in the lowest overall cost.
