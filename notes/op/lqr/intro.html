Introduction

Quadratic

Quadratic refers explicitly to the cost function, i.e. the performance index penalises the states and control inputs quadratically (e.g., $x^T Q x + u^T R u$).

Linear

Linear refers explicitly to the system dynamics. The state-space equations governing the system must be linear (e.g., $\dot{x} = Ax + Bu$). If the system is inherently non-linear, it must first be linearized around an operating point (yielding a Local LQR or iLQR approach) for the standard LQR framework to hold.

Linear + Quadratic

The reason LQR is strictly tied to linear systems comes down to how the optimal control problem is solved. When a linear differential equation is combined with a quadratic cost function, the math works out beautifully. It guarantees that the value function (the minimum cost-to-go) is also quadratic. Because it is quadratic, differentiating it to find the optimal control input yields a linear feedback control law: $$u = -Kx$$ Where $K$ is a constant gain matrix computed by solving the Continuous-time Algebraic Riccati Equation (CARE).

If the system dynamics were non-linear, the sweet spot of this mathematical harmony breaks down. The optimal control law would no longer be a simple linear gain $K$, and the global optimality guarantees and computational efficiency that make LQR so powerful would be lost.
