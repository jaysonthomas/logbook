Introduction

Quadratic

Quadratic refers to the cost function, i.e. the performance index penalises state deviations and control inputs quadratically (e.g., $x^T Q x + u^T R u$).

Linear

Linear refers to the system dynamics. The state-space equations governing the system must be linear. If the system is inherently non-linear, it must first be linearised around an operating point (yielding a local LQR or iLQR approach) for the standard LQR framework to hold.

Linear + Quadratic

Combining a linear differential equation with a quadratic cost function, guarantees a quadratic value function. Because the whole cost function (one step + cost-to-go) is quadratic, differentiating it to find the optimal control input yields a linear feedback control law: $$u = -Kx$$
$$\begin{array}{ccl} K &:& \text{Constant gain matrix computed by solving the} \\ && \text{Continuous-time Algebraic Riccati Equation (CARE).} \end{array}$$
If the system dynamics were non-linear, the optimal control law would no longer be a simple linear gain $K$, and the global optimality guarantees and computational efficiency that make LQR so powerful would be lost. Gemini.

Notes

LQR is applied to trajectory optimisation problems AKA deterministic optimal control problems.
