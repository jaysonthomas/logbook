Stage cost

Overview

Also called running cost or one-step cost. It is a scalar function that quantifies the immediate penalty or performance cost incurred during a single discrete time step of a control loop or trajectory optimisation.

It evaluates how bad the current state $x$ and the chosen control input $u$ are at a particular time instant, ignoring the future or past.

Anatomy

In robotics and autonomy, the aim is to achieve a particular goal state while using as little effort as possible. Because of this, a stage cost is typically broken down into two main components: $$ l(x, u) = \underbrace{\text{State Penalty (Error)}}_{\text{How far off is the target?}} + \underbrace{\text{Control Penalty (Effort)}}_{\text{How hard are the motors pushing?}} $$

State Penalty (Tracking Error)

This penalises the system for deviating from a desired target trajectory or setpoint.

Example: If the desired angle is $\theta_d$, and the current angle is $\theta$, the state penalty might look like $Q(\theta - \theta_d)^2$, where $Q$ is a positive weighting factor.

Control Penalty (Actuator Effort)

This penalises aggressive control inputs to prevent a system from demanding infinite or damaging actuator forces, or to optimise for energy efficiency.

Example: If pushing a lot of torque $u$ burns battery power and can cause mechanical wear, a term like $R u^2$ can be added, where $R$ is a weighting factor penalising high control effort.

Mathematical Properties

To work nicely with mathematical optimisation algorithms (like LQR, Differential Dynamic Programming, or MPC solvers), a stage cost function usually satisfies a few key criteria:
  • Scalar Output
    • It maps a high-dimensional state vector and control vector down to a single, real-valued number ($\mathbb{R}^n \times \mathbb{R}^m \rightarrow \mathbb{R}$).

  • Non-negativity
    • It is designed to be positive semi-definite ($l(x, u) \ge 0$), meaning penalties are accumulated. 0 represents a flawless state of operation.

  • Convexity
    • It is often chosen to be a convex function (like a quadratic form) so that optimisation solvers can easily find a clear minimum without getting stuck in local traps.

Contrast with Total Cost

The stage cost is the fundamental building block of the global optimisation objective. The total cost of an entire trajectory over a time horizon $N$ is the summation of all individual stage costs, plus a final terminal penalty: $$ \text{Total Cost} = \sum_{k=0}^{N-1} l(x_k, u_k) + \underbrace{l_N(x_N)}_{\text{Terminal Cost}} $$
