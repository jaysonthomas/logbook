Aims

  • Setup the environment with objects.
  • Laser emission
    • Emit laser beams to detect objects
    • Render laser lines so visual debugging of the simulation is possible.
    • Emit a tighter, denser grid of lasers.
    • Strip away the idealised simulation elements (the rays and 3D models) so that the visualizer only displays the raw, noisy point cloud data generated by the high-resolution LiDAR sensor.
  • Data collection
    • Collect resulting 3D point data
    • Ignore reflections from own car's roof.
    • Add realistic measurement noise to simulate real-world data.
