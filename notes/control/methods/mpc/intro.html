Overview

LQR is not able to reason about constraints on a system such as actuator limits or safety constraints [Ref]. However, it is still possible to solve the QP (with linear inequalities for e.g.) that LQR is built on even if it is then no longer an LQR problem.

Convex MPC uses the LQR framework whilst also handling constraints. It can be thought of as constrained LQR.

Also called Receeding horizon control.
