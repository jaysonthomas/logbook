Introduction

Overview

[First order taylor expansion]

Linearisation is a useful mathematical tool that's used to tame the math when it becomes hard to work with. It is a process of creating a linear model from a non-linear equation.

The fundamental idea is to approximate a non-linear equation locally by a linear one using the equation:

$$ f_{lin}(x) = f(x_{op}) + f'(x)\Bigr|_{x=x_{op}} \Delta{x} $$
$$\begin{array}{ccl} x &=& x_{op} + \Delta x \\ \Delta{x} &=& x - x_{\text{op}} \end{array}$$
This says that the equation of the best linear approximation of a function around an operating point is the value of the original function plus its slope around the operating point, times the deviation from the operating point.

Geometric intuition

Linearisation is the process of approximating a curved function with a straight tangent line (or a flat hyperplane in higher dimensions) at a specific anchor point - the operating point $x_{\text{op}}$.
  • Away from $x_{\text{op}}$: The tangent line and the true curve diverge, meaning $f_{\text{lin}}(x) \approx f(x)$ is only an approximation.
  • At $x_{\text{op}}$: The tangent line physically touches the curve. Because they intersect at this exact coordinate, their values are identical.
