Base footprint

Overview

This is the world origin frame. It is an empty, mass-less, visual-less dummy link that slides flat along the ground where $Z=0$.

Bot movement

A URDF file is only meant to describe the rigid, internal structure of a robot (how the parts sit relative to one another). It is not responsible for modeling a robot's movement through the world.

Instead, a separate software node - a robot's odometry/localisation system (a differential drive controller or a wheel encoder node) - constantly calculates how far the wheels have spun. It then broadcasts a dynamic, changing transform through the TF (transform) tree from a fixed map point (`odom`) to the robot's floor point (`base_footprint`).

So, when a robot drives across a room:
  1. The software moves `base_footprint` across the virtual world map.
  2. The URDF's `base_joint` ensures that `base_link` (and the entire 3D physical model) tags along precisely above it.
