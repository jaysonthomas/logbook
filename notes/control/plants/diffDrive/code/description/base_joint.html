Base joint

A joint's origin determines where the child link's coordinate frame will be placed relative to the parent link's frame. Shifting the joint origin, shifts the coordinate system of the child link (and everything attached to it).

Physically, the base_joint is a virtual or mathematical joint used for tracking where the robot is relative to the floor.

The base_joint is simply the mathematical rule that ensures the physical body of the robot (base_link) always hovers directly above its floor projection (base_footprint).
