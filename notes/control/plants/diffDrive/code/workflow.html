Work flow

Directory structure


    └── description
      ├── launch 
        └── display.launch.xml
      ├── rviz
      └── urdf
        └── main.urdf.xacro

    └── bringup
      └── config

    ├── CMakeLists.txt
    └── package.xml
Inside CMakeLists.txt, specify the directories to include in the build using install. Refer Colcon's interaction with CMakeLists.

Robot description

Write the urdf files in .xacro formats configuring the various links and joints with details such as:
  • Display colour in RViz
  • Connections
In the main .xacro file:
  • Include the necessary .xacro files.
  • Call functions/macros with the necessary parameters to build the bot.

Rviz configuration

Display launch

This launch file just displays the URDF. It's a .xml file.
  • Set urdf and rviz config paths.
  • Start the first node (robot_state_publisher). Provide the urdf to it.
  • Start the joint_state_publisher_gui node to visualise the sliders.
  • Start rviz.

Configure ros2_control URDF

Within a new .xacro file, specify the:
  • Type and name of the ros2_control module.
  • Joints to be controlled. The types of:
    • Inputs to be commanded/controlled
    • Outputs to be monitored
  • Hardware interface via the hardware tag.
The joints would have to be linked to the hardware interface and each of them to the chosen controllers?

Configure controller

  • Create a package called bringup.
  • Inside a yaml file, configure the controller manager node:
    • Update rate
    • Choose controllers
