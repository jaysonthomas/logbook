Setup

Aim

The aim is to simulate, in discrete time, the control of a simple 1D motion system and publish its trajectory over time.

The controller's job is to drive the state to 0.

Initialisations

State

The system starts displaced from the origin. $$x_0 = \begin{bmatrix} 1 \\ 0 \end{bmatrix}$$

Control

The control input $u$ is acceleration since the mass is 1kg.

Simulation parameters

$$\begin{array}{ccl} h = 0.1 &:& \text{Time step} \\ t_f = 10 &:& \text{Total simulation time} \\ N = \frac{t_f}{h} + 1 &:& \text{Number of simulation steps} \end{array}$$
