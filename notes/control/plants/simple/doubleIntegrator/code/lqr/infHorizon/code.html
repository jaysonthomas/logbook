Simulation manager node

Main function

It sets up a timer to trigger a callback at regular intervals which both:
  • Steps the simulation and
  • Publishes the output

Construction

It is responsible for construction of:
  • Simulation
    • Choice of controller and control frequency.

  • Publisher
    • Choice of message type, queue size and topic name.

Simulation

  • It initialises the plant.

  • It services the following requests from the simulation manager:
    • Controller initialisation

    • Simulation step
      • It steps the controller and the plant's state. It also keeps track of the simulation time.
