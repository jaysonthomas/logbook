Simulation

Overview

Controller

It implements a PID control. Its output is approximated as the $z$ acceleration of the drone.

Actuator

The controller output ($u = \ddot{z}$) changes the torque setpoint of the actuator. The new torque output from the motors causes a change in rotor angular velocities which then changes the force experienced by the system.

System

A change in the force on the system leads to a new $\ddot{z}$. For the coaxial case, since the output of the controller is treated as $\ddot{z}$, the new $\ddot{z}$ is the same as the controller's output. The following intermediate steps are redundant [coaxial drone dynamics]:
  • Conversion from controller output ($\ddot{z}$) to rotor angular velocities.
  • Conversion from $\omega_1, \omega_2$ to $f_1, f_2$.
  • Conversion from thrusts to the drone's vertical acceleration.

Trajectory generator

A 'constant' trajectory of altitude -1m is set as reference with zero target velocity and acceleration. A target point is generated every 10ms for 10s leading to 1000 reference points.

Sensors

At time $t=k$, the output of the controller is used to update the system's velocity $\dot{x}_k$ and the previous velocity is used to update the drone's altitude $x_k$.

Random gaussian noise is added to $x_k$ to get the measurement $y_k$.

The sensor is "sampled" at 100Hz (10ms intervals).
