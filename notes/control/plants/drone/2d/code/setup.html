Setup

Aim

The aim is to control a drone in 2D which is constrained in the vertical direction, thus $z=const$. It can only move in the horizontal direction by changing the roll angle.

State

$$ x = \begin{bmatrix}\phi \\ \dot{y} \\ y \end{bmatrix} $$

Control input

The control input for the drone is simplified to be the roll angle $\phi$.
