Using drake as external lib via cmake

Installation

Download the latest stable release from releases page. v1.54.0 was downloaded. 

    tar -xvzf drake-1.54.0-noble.tar.gz -C $HOME
    $HOME/drake/share/drake/setup/install_prereqs

Test

Download the drake_cmake_installed test code. 

    mkdir build && cd build
    cmake -DCMAKE_PREFIX_PATH=$HOME/software/drake ..
    make
