Getting started

Examples repo

Steps

  • Create ros workspace/src
  • Git clone the control repo
  • Install necessary ros dependencies.
  • Source the ROS setup, build and source the installation setup.

Commands


      cd ws1
      rosdep install -r --from-paths . --ignore-src -y    
      source /opt/ros/kilted/setup.bash
      colcon build --symlink-install
      source install/setup.bash
