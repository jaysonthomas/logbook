Robot state publisher

Inputs

  • It reads the robot's kinematics from the robot_description parameter (URDF).

    • The kinematics informs about the static relationship of links. E.g., the hand is 0.5 meters from the elbow.

  • It listens to /joint_states that provides the dynamic angles.

    • E.g., the elbow is currently bent at 45 degrees.

Use

It runs the FK equations using the inputs to calculate the pose of each link relative to the base. It then broadcasts them as frame transformations to /tf, /tf_static topics. It doesn't know about gravity, friction, mass, or torque. It is purely kinematic.
