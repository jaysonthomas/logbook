Robot state publisher

The robot_state_publisher calculates and broadcasts 3D poses of all the links of a robot. It takes two inputs:
  • URDF via robot_description: This tells the node the static relationship (e.g., "The hand is 0.5 meters from the elbow").
  • Joint States: It listens to /joint_states that provides the dynamic angles (e.g., "The elbow is currently bent at 45 degrees").
By combining these two, it calculates the position of every single part of the robot relative to the base and broadcasts them as TF transforms to /tf, /tf_static. It doesn't know about gravity, friction, mass, or torque. It is purely kinematic.
