Hardware types

Types

Actuator and System components have reading and writing capabilities (using the joint interface), whereas the Sensor component has only reading capabilities (using the sensor interface).
  • Actuator: Simple 1-DOF robotic hardware like motors or valves
  • System: Complex multi-DOF robotic hardware like industrial robots.
  • Sensor: Robotic hardware used for sensing the environment, either related to a joint (e.g., encoder) or a link (e.g., force-torque sensor).

Joints

The <joint> tag groups the interfaces associated with the joints of physical robots and actuators. They have:
  • command interfaces: to set the goal values for hardware
  • state interfaces: to read its current state

    <joint name="my_joint">
      <command_interface name="joint_command_interface">
        <param name="my_joint_command_param">1.5</param>
      </command_interface>
      <state_interface name="joint_state_interface1" />
      <state_interface name="joint_state_interface2" />
    </joint>

Sensors

<sensor> tag groups multiple state interfaces describing, e.g., internal states of hardware. 

    <sensor name="my_sensor">
      <state_interface name="sensor_state_interface1" />
      <state_interface name="sensor_state_interface2" />
      <state_interface name="sensor_state_interface3" />
    </sensor>
