Overview

[Ref]

ros2_control is a framework for the real time control of robots using ROS 2. It provides:
  • A hardware abstraction layer - abstractions on hardware interfaces
  • Controllers that consist of a feedback mechanism.

    • They can receive a setpoint and control an input that is applied to a real robot or to a simulation in Gazebo. For the latter, a gazebo plugin adapter would be required.
