Introduction

Overview

[Ref]

Behavior Trees (BTs) are a way to structure decision-making logic as a tree of nodes that gets "ticked" (evaluated) repeatedly, instead of hand-coding a state machine.

Types of nodes

  • Condition node
    • checks something and returns SUCCESS/FAILURE, never does work (IsBatteryOK)

  • Action node
    • actually does something (MoveForward, Recharge)

  • Control node
    • Sequence (do children in order, stop on first failure) and Fallback (try children in order, stop on first success)
