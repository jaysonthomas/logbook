Directory structure


    ├── launch 
    ├── rviz
    ├── urdf
    ├── CMakeLists.txt
    └── package.xml
Inside CMakeLists.txt, specify the directories to include in the build and the destination. 

    install(
      DIRECTORY urdf launch rviz
      DESTINATION share/${PROJECT_NAME}/
    )
Write the urdf files in .xacro formats configuring the various links and joints with details such as:
  • Display colour in RViz
