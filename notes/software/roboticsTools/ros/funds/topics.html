Topics

Overview

One-way broadcasting like a radio station. A node broadcasts on a specific topic (frequency); anyone tuned in hears it. No handshake, no reply expected.This is used for streaming data. Defined by a message type (.msg).

Diagonostics


    ros2 topic echo /chatter  # Snoop messages
    ros2 topic list
    ros2 topic hz /chatter    # Check frequency

Fundamentals

Choosing appropriate QoS (Quality of Service) profiles (reliability, durability, history depth) — this is one of the most common real-world pain points, especially matching publisher/subscriber QoS or bridging sensor data (best-effort) with control commands (reliable).
