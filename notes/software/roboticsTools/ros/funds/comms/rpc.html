RPC

RPC is a design paradigm for request/response interaction between processes. The main point of RPC is to abstract away the underlying communication mechanism; allowing code in Process A to invoke a function in Process B as if it were a local function call, regardless of whether Process B is running on the same processor or across the globe.

On the same machine, RPC can bypass traditional network layers entirely and use fast local IPC mechanisms like shared memory, OS message queues, or UNIX domain sockets to handle the request and response. It is often referred to as Local Procedure Calls or Inter-Process Communication.

On different machines, RPC packages the request data into network packets (using TCP or UDP) to transmit it across physical hardware.
