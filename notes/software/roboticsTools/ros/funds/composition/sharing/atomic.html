Atomic

Overview

Best suited if the shared resource is a simple scalar type (e.g., boolean flags, counters, status indicators) without requiring heavy locks.

Code

Deadlock, solution.

In the code, multiple threads increment a shared counter, once with a plain int (race condition) and once with std::atomic<int> (safe). Each run will give a different (too-low) counter value. That's because counter++ is actually three steps — read, add, write — and threads can interleave and overwrite each other's updates.

The thread safe version reliably prints the correct total every time, because std::atomic< int>::operator++ guarantees the read-modify-write happens as one indivisible operation — no other thread can see or interleave a partial update.
