    • MutuallyExclusive Callback Groups
      • If the shared resource is accessed exclusively through specific callbacks (e.g., a timer callback or topic callback), those callbacks can be assigned to a MutuallyExclusive callback group. The MultiThreadedExecutor will guarantee that only one thread executes callbacks within that group at any given time, preventing simultaneous access without manually handling mutex locks.
