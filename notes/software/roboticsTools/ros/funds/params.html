Parameters

Overview

Runtime-configurable values for nodes. A node's settings knobs. Can be set via YAML files, command line, or dynamically at runtime.

Mental model: dials on the front of the machine. You can read them, and turn them, without restarting the machine.

Diagonostics


    ros2 run ros2_fundamentals_cpp talker_node
    # in another terminal
    ros2 param list
    ros2 param get /talker publish_rate_hz
    ros2 param set /talker publish_rate_hz 5.0   # watch the talker's terminal speed up live

Fundamentals

Using parameter callbacks to react to changes live, structuring YAML parameter files per-node, and using ros2 param CLI tools for debugging.
