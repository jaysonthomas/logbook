Launch

Overview

Python-based launch files (.launch.py) used to start and configure multiple nodes together.

Mental model: instead of opening five terminals and typing five ros2 run commands, you write the list of commands once and hit play.

Diagonostics


    ros2 launch ros2_fundamentals_cpp fundamentals_launch.py
This single command starts the talker, listener, service server, action server, and param node together, all logging into one terminal. Open a second terminal and run ros2 node list — you'll see all five, even though you only typed one command.

Fundamentals

Composing complex systems (robot bringup — drivers, controllers, planners, visualization) into a single launch, using launch arguments, conditionals (IfCondition), event handlers, and including other launch files for modularity.
