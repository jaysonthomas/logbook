Actions

Overview

A phone call for a task that takes a while. For long-running, preemptible tasks with feedback.

Mental model: ordering food delivery. You place one order (goal), you get progress pings (feedback) while it's cooking, and eventually one final result. You can also cancel it mid-way.

Diagonostics


    ros2 run ros2_fundamentals_cpp fibonacci_action_server_node
    
    # in another terminal — watch the feedback stream in live
    ros2 action send_goal /fibonacci ros2_fundamentals_cpp/action/Fibonacci "{order: 8}" --feedback
Typing Ctrl+C halfway through cancels the goal. 'Goal canceled' will be logged in the server's log. That cancel behavior is the thing services can't do.

Fundamentals

implementing action servers/clients, handling goal acceptance/rejection, cancellation, and feedback streaming — common in navigation (Nav2) and MoveIt-based manipulation.
