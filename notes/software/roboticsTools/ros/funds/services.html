Services

Overview

Synchronous request/response communication for one-off operations (e.g., trigger calibration, get current map). Defined by a service type (.srv).

It is like a phone call, not a broadcast. You call, you wait, you get one answer, then you hang up. Nobody else hears the call. This blocks until a response is received. A topic never returns anything.

Diagonostics


    ros2 run ros2_fundamentals_cpp add_two_ints_server_node
    # in another terminal
    ros2 service list
    ros2 service call /add_two_ints ros2_fundamentals_cpp/srv/AddTwoInts "{a: 2, b: 5}"

Fundamentals

writing service servers/clients, understanding that calls are blocking (or async with callbacks/futures), and knowing when a service is the wrong tool (e.g., long-running tasks — that's what actions are for).
