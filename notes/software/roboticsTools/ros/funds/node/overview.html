Node

Overview

A node is one running program/process that talks to the rest of ROS 2 over the network. A ROS node is capable of:
  • Subscribing and publishing to topics
  • Using timers
  • Logging

Spin

Keeps a node alive and processing callbacks forever. Without this, a program would exit immediately.

Fundamentals

  • Creation of nodes
  • Management of their lifecycle (includes states like unconfigured → inactive → active → finalized)
  • Structure multi-node systems
  • Executors (single-threaded vs multi-threaded)
  • Callback groups for concurrency control
