Introduction

URDF

Unified Robot Description Format is an XML file that contains a complete physical description of a robot:
  • Geometry
  • Kinematics
  • Dynamics
  • Visual aspects
In URDF, a joint's origin is always defined relative to its parent link's coordinate frame, not the world frame.

Mesh

Mesh files are what make a robot look realistic in simulation and visualisation programs. Mesh files visually represent the 3D shape of the robot parts. These files are typically in formats such as STL (Stereo Lithography (.stl) or COLLADA (.dae)).

XACRO format

XACRO files are like blueprints for URDF files, using macros and variables to simplify complex robot descriptions. They need to be processed into URDF files.
