Joint angle representation

In robot description files, robots are specified using relative poses of each link - 6 numbers: x, y, z, roll, pitch, yaw.

In code, $3\times 3$ rotation matrix representation is used for each joint angle, when a series of frame transformations through all the joints is performed to get the full kinematics. In vector form, each joint is represented by 7 numbers - 3 for translation, 4 for the quaternion joint angle representation.
