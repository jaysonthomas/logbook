Forward kinematics

Overview

Forward kinematics maps joint angles to a gripper pose. $$ ^WX^G = f^G_{kin}(q) $$ Given the joint angles:
  • Compute the pose of the gripper relative to the wrist
  • Chain it backwards all the way to the world frame
The math is simple because each individual joint simply describes a small rotation operation from right before the robot's joint until right after the robot's joint. Joints are operations that make a transformation from a pre-joint frame to a post-joint frame.

This is how robots are specified in robot description files as relative poses of each link - 6 numbers: x, y, z, roll, pitch, yaw.

Drake implementation

The context is taken as the argument instead of $q$ because the kinematics can be parameterised. If the link lengths need to be changed for instance, then the kinematics need to reflect that.
