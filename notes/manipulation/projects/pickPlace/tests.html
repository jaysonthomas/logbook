Tests

Feedforward

Choose the initial configuration of the robot that puts the end-effector exactly at the first reference configuration. Set $K_{p}=K_{i}=0$. With zero disturbance, the bot should follow the trajectory perfectly. There might be small numerical errors in the euler integration step which will be fixed using the feedback controller.

Add a small error to the initial configuration.

Feedback

With a small error in the initial configuration, add a positive-definite diagonal proportional gain matrix $K_{p}$ while keeping the integral gains zero.

The convergence exhibited by the controller does not necessarily have to be fast. It is more interesting if the convergence is not too fast, so the transient response is clearly visible. The motion should be smooth, with no overshoot, and very little error.
