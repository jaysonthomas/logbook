Aim

The overall aim is for a gripper to pick up and drop off a brick at a desired location.

There is a gripper frame and an object frame attached to the gripper and the object respectively. To grasp, the gripper frame needs to be in the right orientation and position w.r.t. the object frame.

A smooth reference trajectory in end effector coordinates needs to be converted to a smooth trajectory in joint space, avoiding kinematic sigularities.
