Diff IK

Parameters

Holds velocity and joint limits, gains for DiffIK. Number of joints/velocities is 7.

Use

DifferentialInverseKinematicsIntegrator creates the controller. It continuously solves: $$ J(q) \dot{q} = V_d $$ It integrates $\dot{q}$ to produce joint positions $q$.

IO

Inputs: robot model (controller plant), Ee frame, controller timestep and params.

Expose the controller's joint-position output as the diagram's "iiwa.position" interface. Expose the plant's full state so other systems can access it.

Connect the plant's state output port to the controller's 'robot state' input port. DiffIK needs the current robot state.

Pose trajectory source

  • Generates end-effector pose as a function of time.
  • Connect the output port of Traj generator to the 'desired pose' input port of diff IK.
  • If no trajectory is provided, all joint positions are set to 0.

Gripper

  • Using a constant vector source, set the grippers position to or open the gripper by 10cm.
  • Expose the gripper's position output port.

Diagram build

  • Build the complete system.
  • Name the diagram, which is useful for debugging.
  • Get pointers to the gripper (body) frame and the world frame. Useful for pose computations.
  • Create the default context, i.e. the initial simulation state. It stores joint positions, velocities, time, parameters.
  • Publish the current geometry to Meshcat.
