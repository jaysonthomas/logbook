Make hardware station

Overview

It creates a simulation station with physics, sensors, controllers and visualisation.

Function signature

Return

RobotDiagram is Drake's wrapper around a Diagram containing a MultibodyPlant, SceneGraph, controllers, sensors, etc.

Arguments

  • Scenario

    • Scenario contains all configuration information such as: robot models, controllers, cameras, visualization, LCM buses, plant configuration.

  • Meshcat server
  • List of package.xml files.

    • Used so Drake's parser can resolve package://my_robot/... URIs.

  • parser_preload_callback

    • Optional callback executed before models are loaded. Useful for adding package paths, registering custom parsers, adding package maps.

  • parser_prefinalize_callback

    • Called after loading models and before the plant is finalised. Useful for adding joints or modifying the plant.

  • prebuild_callback

    • Callback executed just before building the diagram. Useful for adding custom systems.

Plant

  • RobotDiagramBuilder internally creates DiagramBuilder, MultibodyPlant and SceneGraph with the specified time step.
  • Configures the plant. Applies options like time step, contact solver, gravity, friction, penetration allowance

Load models

  • Create parser.
  • Load packages to be able to discover models.
  • Configure parser with the package map.
  • Preload callback. Read directives to figure out what to load. Run the pre finalise callback to allow for further mods.

Plant finalisation

  • Apply driver configs. Some controllers need access before finalising such as joint stiffness control.
  • Add bodies, joints, actuators before finalise. Then lock the topology.
