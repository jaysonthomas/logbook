Probabilistic Roadmap Method (PRM)

Overview

PRM randomly samples a workspace, building up a graph to represent the free space. For every randomly generated node, PRM checks whether it lies in the freespace or is in collision with an obstacle.

It goes through 2 phases:

  • Learning
  • Query

Learning phase

The learning phase involves building up a graph.

Steps

  • Generates/samples a new random configuration represented by a node in the graph.
  • Checks if it is in collision.
  • If not in collision, then PRM tries to connect the node to its neighbours.

Neighbours selection

PRM can look for any number of neighbours within a certain radius of a node, or it could look for a node's K nearest neighbours.

Neighbours connection

Once the neighbours have been selected, PRM will see if they can successfully create an edge to each of its neighbours, avoiding collisions. The local planner must find a path between two nodes or return that such a path does not exist.

One easy way to accomplish this is to draw a straight line between two nodes, and then check if any part of it collides with an obstacle.

Collision check

Place a number of evenly spaced samples on the line joining 2 nodes and see whether any one of them is in a collision.

One can work incrementally starting on one side of an edge and moving towards the other, or one can take a binary approach, checking the sample at the midpoint first. If it is not in collision, one could continue breaking the edge up into segments, checking each midpoint sample for a collision. If all of the samples have no collision found, then the edge can be added to the graph.

Query phase

The process of adding new nodes and connecting them to the graph continues. Eventually, a certain criteria is met, such as a specific number of nodes or edges have been created, or a particular amount of time has elapsed. At this point, the learning phase is over.

PRM then enters the query phase, where it uses the resulting graph to find a path from start to goal. First, it must connect each of these to the graph. PRM does so by looking for the nodes closest to the start and goal and using the local planner to try to build a connection.

If this process is successful, then a search algorithm like A star search can be applied to find the path from start to goal. The resulting path may not be optimal, but it proves that moving from start to goal is feasible.
