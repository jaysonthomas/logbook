Kalman gain

Overview

If $L$ is selected based on traditional methods like pole placement, then it is called a Luenberger observer. It would be similar to having a linear feedback that is not optimal, i.e. not LQR. If it's optimised, it's called the Kalman Gain.

KF can be seen as a weighted average between two uncertain sources of information:

  • Prediction (where physics/math thinks the system is)
  • Sensor measurement
Kalman Gain is the weight factor that decides how much a new measurement is trusted compared to the belief after the prediction step, when updating an estimate.

Derivation

Kalman gain is derived from the estimated state covariance (actual vs estimated after considering the measurement update). $$ E[(x_k - \hat{x}_{k|k})^T(\dots)] == \text{tr}(\Sigma_{k|k}) $$ A state covariance is the same as its trace [ref].

MMSE's idea of minimising the state covariance is used in KF to find the optimal gain. Using the covariance equation, minimise the state covariance by setting its derviative to 0 and solve for $L_k$.

$$\begin{align*} arg \min_{L_k} \quad & \text{tr}(\Sigma_{k|k}) \\ \frac{\partial \, \text{tr}(\Sigma_{k|k})}{\partial L_k} &= 0 \\ L_k &= \Sigma_{k|k-1} C^\top S_k^{-1} \end{align*}$$
$$\begin{array}{ccl} \Sigma_{k|k-1} &:& \text{Predicted state covariance - actual vs predicted state.} \\ C &:& \text{Measurement model.} \\ S_k &:& \text{Innovation covariance - measurement vs predicted measurement.} \end{array}$$
Refer intuition.

Inputs

$K$ is computed:
  • Using the Jacobian of the measurement model and
  • indirectly, the Jacobian of the state transition function which helps compute the estimate of the state covariance matrix.
$$\begin{align*} H_t &= h'_t(\bar{\mu}_t) \\ K_t &= \bar{\Sigma}_t \; H^T_t \; (H_t \bar{\Sigma}_t H^T_t + R_t)^{-1} \end{align*}$$

Steps

The Kalman gain calculation involves the following 3 steps:
  • Inside the bracket, the estimated covariance is transformed into the measurement space using $H$.

  • Measurement noise $R$ is added to it.
    • There is uncertainty associated with sensor measurements due to sensor inaccuracy, which is captured by the covariance matrix $R$.

  • (Outside the bracket) The result is then transformed back into the state space to get the Kalman gain.
